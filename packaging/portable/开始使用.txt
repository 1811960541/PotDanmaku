PotDanmaku 独立便携版 @@VERSION@@

完整解压后，双击 PotDanmaku.App.exe。
已包含 .NET 运行环境，无需安装 .NET 或 SDK，无需项目源码。
复制或移动程序时，请保留整个文件夹。

1. 在 PotPlayer 中打开视频。
2. 弹幕与视频放在同一目录并使用同一主文件名，例如 第01集.mkv 与 第01集.xml。
3. 打开工具，唯一的播放器默认自动连接，并自动加载同名 XML、JSON 或 ASS。
   多个播放器时手动选择目标；没有同名文件时可选择或拖入弹幕。
4. 倍速保持“自动读取”，支持日常 3 倍速。

PotPlayer 切换下一集后自动加载对应弹幕，没有匹配文件则清除旧弹幕。
手动关联、时间偏移和显示设置按视频路径记忆，下次打开自动恢复。
普通暂停会冻结当前弹幕位置，恢复后继续移动。

切到其他软件后，只要视频可见，弹幕仍会显示。
本版一次只给一个视频叠加弹幕。

配置自动保存在程序旁的 data 文件夹，首次运行时创建。
升级时先退出旧版，完整解压新包，再复制旧版 data 文件夹以保留配置。
暂停后立即小幅向前跳转仍有缓存识别限制，详见 README.md。
详细说明见 README.md 和 docs/使用说明.md。PotPlayer 不包含在本包中。
