# PotDanmaku

版本：**@@VERSION@@** · Windows x64 便携预发布版

为 PotPlayer 播放本地 XML、JSON 和 ASS 弹幕，支持 3 倍速同步、自动加载与切集、按视频记忆弹幕和显示设置。PotPlayer 原有的对白字幕可继续使用。

[项目主页](https://github.com/1811960541/PotDanmaku) · [版本下载](https://github.com/1811960541/PotDanmaku/releases) · [问题反馈](https://github.com/1811960541/PotDanmaku/issues)

## 开始使用

1. 将压缩包完整解压到可写目录，运行 `PotDanmaku.App.exe`。包内已包含 .NET 运行环境，无需安装 .NET 或 SDK。
2. 在自行安装的 PotPlayer 中打开本地视频。
3. 将弹幕与视频放在同目录并使用相同主文件名，例如 `第01集.mkv` 与 `第01集.xml`。工具默认连接唯一的播放器并自动加载；多个播放器时手动选择目标。
4. 也可选择或拖入不同名称的弹幕。成功导入后会记住视频关联，下次打开同一路径的视频恢复设置。
5. 保留 PotPlayer 的对白字幕，关闭播放器中同一份弹幕 ASS，避免重复显示。

需要 Windows x64 和支持 D3D11 的显卡驱动；已在 Windows 11 验证。PotPlayer 不包含在本包中。移动程序时请保留整个目录。

## 日常使用

- 自动匹配优先使用保存的关联，再按同目录同名 XML → JSON → ASS 查找。切到下一集时重新匹配，找不到时清除上一集弹幕。
- 在 PotPlayer 中设置 3×，工具保持“自动读取（含 3×）”。默认横穿时长 18 秒按视频时间计算，3×下约为 6 秒实际时间；需要更慢时增加时长。
- 调整“弹幕延后”可以修正时间，正数延后、负数提前。字号、区域、颜色、透明度、密度和边距可在界面设置。
- 点击其他软件后，可见视频上的弹幕继续显示。其他窗口遮住视频时也会遮住弹幕；最小化或隐藏播放器时隐藏覆盖层。
- “收起到托盘”后继续运行，双击托盘图标打开设置；关闭主窗口退出程序。

## 配置与升级

首次运行会在程序旁创建 `data`，保存全局设置、视频关联、日志和诊断。目录不可写时提示并回退到 `%LOCALAPPDATA%\PotDanmaku`。

升级时先退出旧版，完整解压新包，再将旧版 `data` 复制到新目录；不要只替换 EXE。视频移动或改名后需要重新关联，配置迁移不会复制视频或弹幕文件。

## 支持范围

- XML：常见 B 站弹幕 XML，支持滚动、反向、顶部和底部固定类型。
- JSON：`potdanmaku/v1` schema，示例见 `samples/demo.json`。
- ASS：导入时间、正文、基础颜色与透明度后重新排布；普通对白默认排除，复杂特效跳过并报告，支持样式筛选。
- 同时只维护一个播放器弹幕会话。自动匹配需要可识别的本地视频路径；其他来源仍可手动导入。
- 暂停后首个缓存周期内，第一次小幅向前跳转可能被当作进度补报忽略；稍后或再次调整、向后或大幅跳转仍生效。
- HDR、独占全屏、多屏 DPI、休眠恢复和长时间稳定性仍有待完整兼容验证。

完整操作说明见 [使用指南](docs/使用说明.md)。
