# PotDanmaku 独立便携版

版本：@@VERSION@@ · Windows x64

## 开始使用

1. 将压缩包完整解压到一个可写文件夹。
2. 双击 `PotDanmaku.App.exe`。程序已包含 .NET 运行环境，不需要项目源码、.NET SDK 或安装脚本。
3. 在已安装的 PotPlayer 中打开本地视频。只有一个播放器时，工具默认自动连接；有多个时，选择目标并点击“连接并播放弹幕”。
4. 将 XML、JSON 或 ASS 弹幕放在视频同目录并使用相同主文件名，例如 `第01集.mkv` 与 `第01集.xml`。工具会自动加载；也可手动选择或拖入其他名称的弹幕。
5. 保留 PotPlayer 的对白字幕，关闭播放器内的同一份弹幕 ASS，避免重复显示。

复制到其他电脑时请保留整个文件夹。PotPlayer 不包含在本包中。优先使用 Windows 11 x64，以及支持 D3D11 的显卡和驱动。

## 日常使用

- 自动加载：优先恢复此视频保存的弹幕关联；没有可用关联时，按同目录同名 XML → JSON → ASS 查找。文件名必须准确匹配，不模糊猜测集数。
- 自动切集：PotPlayer 打开其他视频或进入下一集后，会加载对应弹幕；下一集没有匹配文件时清除上一集弹幕并提示手动选择。点击停止会暂停自动连接，手动连接后可继续跟随。
- 视频记忆：手动导入成功后记住视频与弹幕的关联，并保存时间偏移、显示设置、编码和 ASS 筛选选项。下次打开同一路径的视频自动恢复；不同目录的同名视频各自保存，视频移动或改名后需要重新关联。
- 3 倍速：保持“自动读取（含 3×）”，在 PotPlayer 设置 3× 即可。默认横穿时长 18 秒对应约 6 秒实际时间，需要更慢可增加横穿时长。
- 暂停与恢复：本版修复暂停时缓存进度导致的闪动、位置回退，以及恢复后的误判跳转；普通暂停保留最后显示的位置。
- 边看边做事：点击其他软件后，弹幕继续显示在可见的视频上；其他窗口遮住视频时也会遮住弹幕。可使用 PotPlayer 自带置顶功能让视频保持可见。
- 托盘：点击“收起到托盘”后继续运行；双击托盘图标打开设置。关闭主窗口会退出工具。
- 样式：可调整字号、区域、透明度、描边、时长、密度和时间偏移，支持 ASS 按样式筛选。
- 刷新：默认跟随显示器，可选上限 60 或 120 FPS。

## 配置与迁移

本包默认启用便携模式，配置、日志和诊断保存在程序旁的 `data` 文件夹，首次运行时自动创建。程序目录不可写时会提示并回退到本地用户配置目录。

新包包含默认设置，不带开发电脑的个人配置或测试数据。原项目版的设置位于 `%LOCALAPPDATA%\PotDanmaku\settings.json`；需要保留时，退出程序后将该文件复制到本包的 `data\settings.json`。也可以直接在界面重新调整。

从旧便携版升级时，先退出旧程序，完整解压新包，再把旧目录的 `data` 文件夹复制到新目录；不要只替换一个 EXE。全局显示设置保存在 `settings.json`，本版视频关联保存在 `video-associations.json`。程序原子保存并保留上一份备份；迁移不会复制视频或弹幕本身。

## 格式与支持范围

- XML：常见 B 站弹幕 XML，支持滚动、反向、顶部和底部固定类型。
- JSON：`potdanmaku/v1` 格式；示例见 `samples/demo.json`。
- ASS：导入时间、正文、基础颜色与透明度，按本工具设置重新排布；复杂特效会跳过并报告，不会修改原文件。
- 多视频：可从多个 PotPlayer 实例中选择一个目标；当前一次只给一个视频叠加弹幕。
- 自动匹配依赖播放器返回本地视频完整路径；网络来源或不支持该接口的播放器版本仍可手动导入。
- 缓存接口无法可靠区分暂停后第一个缓存周期内的小幅向前跳转与最终暂停位置补报，此时第一次小幅前跳可能被忽略；稍后或再次调整、向后或大幅跳转仍生效。规则见 `docs/暂停衔接修复.md`。

这是开发试用版。新功能和暂停修复已完成自动化及本机短时检查，日常正片观看、多屏、真实休眠、完整全屏输入、两小时稳定性及干净系统仍有待完整验收。历史验证和已知限制见 `docs`，第三方许可见 `THIRD-PARTY-NOTICES.md` 与 `licenses`。

## 文件校验

`release-info.json` 记录版本和打包信息，`files.sha256` 记录包内文件的 SHA-256；压缩包旁的 `.sha256` 文件用于校验整个压缩包。运行产生的 `data` 不在文件清单中。
