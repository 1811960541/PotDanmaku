# PotDanmaku

Windows 上的 PotPlayer 弹幕工具。从本地 XML、标准 JSON、ASS 导入弹幕，由独立 GPU 窗口绘制，并跟随 PotPlayer 的播放时间。播放器内的对白字幕可以继续使用。

公开仓库：[1811960541/PotDanmaku](https://github.com/1811960541/PotDanmaku)。仓库包含源码、测试、小型合成样本、构建脚本和文档；`artifacts`、`releases`、个人配置、日志和诊断不纳入 Git。文中便携包路径指本地打包产物，克隆仓库后需自行构建生成。本次公开上传的检查范围见 [公开上传检查](docs/公开上传检查.md)。

当前版本为 **0.2.0-alpha.1**，已提供 Windows x64 独立便携包，旧 alpha.6 保留。新版本包含同名弹幕自动加载、播放列表切集跟随，以及按视频记忆弹幕关联、时间偏移和显示设置。110 项核心测试通过，实际发布程序集在项目外通过 11 项会话检查和真实 PotPlayer 1×/3×六次暂停恢复检查，并确认使用包内运行环境。行为说明见 [自动加载与视频设置记忆](docs/自动加载与视频设置记忆.md)，发布检查和剩余验收见 [本版发布记录](docs/0.2.0-alpha.1发布记录.md) 及 [开发计划第 10.5 节](开发计划.md#105-020-alpha1-源码进展与待发布事项)。

## 从源码运行

需要 Windows x64、.NET SDK 10.0.401（允许同一补丁系列滚动）、PotPlayer 和支持 D3D11 的显卡驱动。首次还原依赖需要网络，正常播放离线运行。

```powershell
git clone https://github.com/1811960541/PotDanmaku.git
cd PotDanmaku
dotnet test PotDanmaku.sln -c Release
dotnet run --project src/PotDanmaku.App -c Release
```

生成自带运行环境的便携包：

```powershell
.\tools\publish.ps1
.\tools\package-portable.ps1
```

产物生成到本地 `releases`，完整解压后运行 `PotDanmaku.App.exe`。开发与验证命令见下文。

alpha.2 修复了延迟播放器采样造成的周期性时钟超前和回拉；此前提交帧率正常并不代表文字位置更新正常。修复说明见 [平滑移动修复](docs/平滑移动修复.md)。使用 alpha.1 或 M0 的用户需要退出旧程序，运行新的发布目录。

已实现：文件选择和拖入、导入报告、四种弹幕类型、密集轨道防追尾、暂停和跳转同步、时间偏移、颜色和透明度、顶部区域与边距校准、配置保存、诊断导出。当前是可以试用的开发版，后续验收见 [开发计划](开发计划.md) 和 [本轮验证](docs/文件导入与轨道验证.md)。

## 启动与使用

alpha.6 修复任务栏图标偏小：窗口图标保留 ICO 的多尺寸解码信息，让 WPF 为任务栏和标题栏分别选择合适的图像。原有托盘图标保持不变。原因与验证见 [任务栏图标修复](docs/任务栏图标修复.md)。

独立便携包位于 `releases/PotDanmaku-0.2.0-alpha.1-portable-win-x64.zip`，完整解压后直接双击其中的 `PotDanmaku.App.exe`。该包自带 .NET 运行环境，默认把配置保存到程序旁的 `data`，附有简明使用说明、许可及文件校验清单，不需要项目源码或开发工具。升级便携版时，先退出旧版，再将旧目录的 `data` 文件夹复制到新目录以保留配置。

可直接运行 `releases\PotDanmaku-0.2.0-alpha.1-portable-win-x64\PotDanmaku.App.exe` 使用已打包版本。该版自带 .NET 运行环境，复制给其他电脑时保留整个目录。需要支持 D3D11 的显卡和驱动。

从源码运行时，在项目目录执行 `dotnet run --project src/PotDanmaku.App -c Release`，需要 .NET SDK。根目录的 `启动.ps1` 优先使用开发发布目录，再查找与源码版本对应的便携目录；两者不存在时从源码运行。直接打开上述 `releases` 中的 EXE 可明确使用便携版。

以下说明适用于 0.2.0-alpha.1；自动连接、切集和视频设置恢复的完整规则见上方功能记录。

1. 在 PotPlayer 打开视频。
2. 将弹幕与视频放在同目录，使用相同主文件名；打开 PotDanmaku 后，唯一的 PotPlayer 默认自动连接，并优先恢复保存的弹幕关联，再按 XML → JSON → ASS 查找同名文件。也可选择或拖入弹幕并保存手动关联。
3. 有多个 PotPlayer 时，选择目标并点击“连接并播放弹幕”。打开新视频或切换下一集会自动重新匹配；没有匹配文件时清除旧弹幕并提示。导入数量和问题可在“导入报告”查看。
4. 保留播放器的对白字幕，关闭同一份弹幕 ASS，避免重复显示。
5. 若弹幕覆盖播放列表或控制栏，展开“覆盖区域校准”，调整右、上、下边距。它们表示整个播放器客户区的百分比，随后按视频宽高比适配。

“独立预览”不依赖播放器，从弹幕时间轴开头播放。没有导入文件时使用内置示例；`samples` 提供同一组弹幕的三种格式。播放器或预览失焦后仍显示弹幕，可以一边看视频一边操作其他软件；最小化或隐藏时才隐藏覆盖层，恢复可见后继续查询当前时间。若希望视频一直浮在其他软件之上，请使用 PotPlayer 自带的置顶功能；弹幕跟随播放器的窗口层级。

多个视频：能够识别多个 PotPlayer 实例，并在下拉框中选择一个连接；当前只维护一个播放会话，不能同时给多个视频分别加载和显示弹幕。连接另一个播放器会停止原会话。多视频独立弹幕属于后续功能。

点击“收起到托盘”，或最小化主窗口，可继续在后台同步。双击托盘图标打开设置；右键菜单可开关弹幕或退出。关闭主窗口仍然退出程序。“显示弹幕”开关只控制显示，时间继续同步，重新开启时显示当前应出现的弹幕。

同一配置目录只运行一个主程序；再次启动会打开已有设置窗口，避免重复叠加。便携模式与普通模式使用各自的配置目录，检查和冒烟命令不受此限制。

默认字号为 16 个 1080 高度参考单位，横穿时长 18 秒，显示区域为顶部 25%，最多 13 行。实际行数根据字体测量与描边计算，默认通常为 10 行；屏幕物理字号随视频区域高度缩放。底部固定弹幕位于所选区域的底部。拥挤、过长或超过同时显示上限的弹幕会跳过，界面显示相应数量。

“弹幕延后”以秒计：正数延后，负数提前。渲染查询时间 = 视频时间 − 偏移；暂停时调整偏移同样立即生效。手动导入新文件时偏移重置为零，随后调整会按当前本地视频保存；重新打开该视频自动恢复偏移和显示设置。字号、区域、时长、密度、透明度、描边、最多行数、颜色开关和四边距仍保存为全局配置；视频关联另存 `video-associations.json`。普通模式的配置目录为 `%LOCALAPPDATA%\PotDanmaku`，便携模式为程序旁的 `data`。

“更多显示设置”提供刷新和倍速选项。通常保持“跟随显示器”和“自动读取（含 3×）”。3× 时，18 秒的横穿时长对应约 6 秒实际时间；需要更慢可增加横穿时长。手动倍速仅用于接口返回无效速度的播放器版本，并须与 PotPlayer 的实际倍速一致。60/120 为提交频率上限，实际呈现节奏还取决于显示器与 DWM。

配置升级时保留 v1 原文件备份，每次原子保存也保留上一份配置。使用 `--portable` 启动，或在程序旁放置 `portable.flag`，配置、日志和诊断改存程序旁的 `data`；目录不可写时提示并回退到本地用户目录。日志只记录状态和统计，每个约 1 MB，保留当前及 3 份历史，不记录完整弹幕正文。

## 文件支持范围

| 格式 | 支持 |
| --- | --- |
| B 站 XML | `<i><d p="时间秒,类型,字号,十进制RGB,…">正文</d></i>`；类型 1/2/3 滚动、4 底部、5 顶部、6 反向；特殊类型跳过 |
| JSON | 明确的 `potdanmaku/v1` schema，整数毫秒；不会猜测其他导出器的字段与时间单位 |
| ASS | Events 的时间、正文、样式主颜色与透明度；水平 `move`、固定 `pos`、基础初始颜色/透明度覆盖；按工具设置重新排布 |

XML/JSON/ASS 原始字号保留为导入元数据，实际统一使用界面的字号。ASS 的原坐标、原结束时间、字体和动画特效不会原样复现。卡拉 OK、绘图、旋转、变换、分段覆盖、非水平运动、Effect 等复杂事件会跳过并报告。ASS 正文中的逗号、换行和基础空格转义可以读取。无定位的普通对白默认排除，确需显示时勾选“也导入无定位的普通字幕”；识别到 Bilibili Evolved 弹幕转换器标记时会按弹幕处理。

ASS `Timer` 非 100 时显示提示，当前按 Events 时间戳直接导入，不做 Timer 缩放。请以对应视频时间轴核对。原始文件始终保持不变。

导入 ASS 后可以点击“ASS 按样式筛选…”，查看各样式的事件数量并选择需要的样式。明确选中的样式包含其中的普通对白，因此混合字幕文件应排除对白样式；复杂特效仍会跳过。报告单列“样式排除”，不会把用户筛掉的事件算成解析错误。

默认严格读取 UTF-8，支持 UTF-8/UTF-16 BOM；旧编码文件可以选择 GB18030 后重新打开。不会用替换字符静默吞掉解码错误。文件上限 100 MB，记录上限 50 万，正文上限 500 个 Unicode 字符；导入和排布都在后台执行并支持取消。单条无效记录会报告，整份文件的结构或编码错误会保留上一份弹幕。

JSON 示例：

```json
{
  "schema": "potdanmaku/v1",
  "timeUnit": "ms",
  "comments": [
    { "time": 1250, "text": "道友请留步", "mode": "scroll", "color": "#5EEAD4", "opacity": 0.9 }
  ]
}
```

每条必需 `time`、`text`；可选 `id`、`mode`（scroll/reverse/top/bottom）、`color`（#RRGGBB）、`opacity`（0～1）、`fontSize`。未知 schema 拒绝导入，未知 mode 单条跳过。

## 同步与渲染

50 ms 后台读取 PotPlayer 的进度、状态和倍速，每次通信设置超时。独立单调时钟平滑外推，跳转后直接查询确定性的当前弹幕，不补发整段历史。暂停后位置冻结；所有位置基于媒体时间计算，所以倍速变化会影响弹幕移动速度。

每行共用碰撞检查，滚动、反向和固定弹幕相互避让。排布比较整个同时存在时段的相对位置，避免长弹幕追上短弹幕；没有安全空位时跳过。调整字号、时长、区域或窗口尺寸会重新排布。

原生透明 HWND 承载 D3D11 / DXGI / Direct2D / DirectWrite / DirectComposition，专用线程绘制，鼠标输入穿透。提交统计与 DXGI 计数是诊断数据，不等同于物理屏幕逐帧测量。

已实测真实 ASS 密集播放、暂停、暂停跳转及 3× 连续播放；设备重建经应用内故障注入验证。设备丢失等已知临时错误会按退避间隔自动重建，连续失败最多重试 5 次；其他错误会停止并提示，仍可手动连接。显示设置变化、跨屏/DPI 变化和休眠恢复会请求重建；“诊断与统计”也可手动重建绘制层。完整倍速切换矩阵、真实显卡重置/休眠、多屏 DPI、HDR、独占全屏和两小时稳定性仍需验收。视频区域为估算，复杂皮肤可能需要校准；切换视频按本地路径自动重新匹配，不再仅凭标题变化要求重新连接。自定义快捷键属于后续版本。

渲染冒烟测试（测试期间保持目标窗口可见，可以切到其他软件）：

```powershell
dotnet run --project src/PotDanmaku.App -c Release -- --smoke --file samples/demo.json --seconds 20 --output artifacts/smoke
dotnet run --project src/PotDanmaku.App -c Release -- --playback-smoke --file samples/demo.ass --seconds 30 --output artifacts/player-smoke
```

`--smoke` 使用独立预览，可加 `--start 60` 从第 60 秒开始；`--playback-smoke` 自动连接首个 PotPlayer，可用 `--pid` 指定进程。退出码 0 表示提交超过 60 帧、排布非空、无图形错误且窗口命中测试通过；2 表示冒烟条件未满足；1 表示导入/连接/异常失败。这些条件不代表完整产品验收通过。

冒烟测试可加 `--frame-limit 60` 或 `120`，加 `--simulate-device-loss` 在中途注入应用内模拟设备错误；这不会重置系统显卡。测试保持目标窗口可见，结果需检查恢复前后都有帧。通常加 `--portable` 避免更改日常配置；正常 GUI 冒烟不会创建托盘图标。诊断额外生成 `window-samples.json`，记录目标失焦、最小化、系统遮蔽、置顶属性、覆盖层相对层级和定位前后的前台窗口，不记录其他软件标题或正文。

界面的“导出诊断”保存到 `%LOCALAPPDATA%\PotDanmaku\diagnostics\时间戳`：`summary.json`、`frames.csv`、`player-samples.json`。分别记录导入/排布统计、配置和渲染健康状态，最多前 100,000 帧，以及最多 20,000 条播放器采样。CSV 中的 `x_ref` 是首条活跃弹幕在参考坐标下的位置，`first_source_index` 标识它；alpha.2 增加播放状态、倍速、采样延迟、弹幕类型和物理坐标，分析脚本会检查移动坐标是否停顿、时钟是否突然跳动。诊断不记录正文，但包含文件名和播放器标题。

