# 3 倍速与 M4 验证

日期：2026-10-04。版本：0.1.0-alpha.3。环境：Windows 11 x64，系统构建 26200，本机 160 Hz；测试结果仅针对本机。

## 已交付

- 3× 的缓存误差按媒体倍速换算。此前在约半秒的进度缓存中途连接时，误差会放大到约 1500 ms，旧阈值可能误判 seek；新增测试先复现该问题，再修复。
- 托盘收起、双击打开设置、显示开关和退出。关闭主窗口仍退出；隐藏弹幕不重设时钟。
- 同配置目录单实例；收起后再次启动可恢复已有设置窗口，避免重复覆盖层。
- 跟随显示器、上限 60/120 FPS；渲染线程使用可取消的高精度等待，不忙循环。
- 无有效速度查询时可显式选手动 0.5/1/1.5/2/3×，默认自动读取。手动速率必须与播放器一致，尚无自动估速。
- ASS 样式数量、筛选与重新导入，用户排除单列统计；选中样式包含普通对白，复杂事件仍报告跳过。
- 已知 DXGI/D2D 设备错误自动释放并重建，连续失败最多 5 次，退避 0.5/1/2/4/8 秒；保留播放会话、时钟和诊断。显示设置、跨屏/DPI 变化和休眠恢复请求重建；未知错误仍停止并提示。
- 配置 v1→v2 备份、原子替换及上一份备份；--portable / portable.flag，程序旁 data 不可写时回退本地用户目录；约 1 MB 日志滚动，保留 3 份历史，不记录正文。
- 版本 ZIP 和 SHA-256；压缩包排除便携配置、日志和诊断。tools/stress.ps1 可复现 XML 压力检查。

## 自动回归

Release 构建零警告、零错误；80/80 测试通过。覆盖真实 1×/3×采样重放、延迟与半秒缓存、3×不同缓存相位连接、1↔3 与 0.5↔3 切换、暂停/恢复/前后跳转、轨道碰撞、格式错误、ASS 样式过滤、配置迁移与备份、设备错误分类及退避边界。

真实 3× 回归夹具来自 artifacts/alpha3-player-3x/player-samples.json 的前 110 条快照，时间平移为相对单调秒，保留原始进度；不包含弹幕正文或播放器标题。

用约 20 分钟的 25 fps 网格视频保持实际播放器运行，加载现有真实 ASS 45,804 条可解析事件，采集约 90 秒。诊断采样的 Rate=3、RawSpeed=3000，使用自动读取，未用手动速率替代。

数据：artifacts/alpha3-player-3x/{summary.json,frames.csv,player-samples.json,analysis.json}。DXGI 计数和提交间隔不是摄像机对物理屏幕逐帧的测量；原 ASS 和网格视频只用于同步与负载，不能证明正片时间轴已匹配。

弹幕横穿时长仍按视频时间定义，默认 18 秒在 3× 下约为 6 秒实际时间；用户可以增加时长。此版本尚未取得用户对 3× 阅读舒适度的观看反馈。

## 3× 全屏暂停、跳转与恢复

实际 PotPlayer 无边框全屏，诊断视口为 3840×2160，仍使用原有 45,804 条 ASS 负载、自动读取 3×。

- artifacts/alpha3-player-3x-fullscreen：约 100 秒，记录 15,865 帧、最多 200 条同时显示，提交间隔 P95 6.423 ms；暂停在 101,418 ms 的 11,330 帧，位置、首条事件和活动数量均保持不变。正常播放帧没有回退、超大步进或同条滚动停顿，命中穿透通过，无图形错误。
- artifacts/alpha3-fullscreen-seek：约 50 秒，记录 7,936 帧。暂停在 101,418 ms 的 2,947 帧保持不变，使用播放器向后跳转键后进度变为 90,000 ms；该位置的 3,851 帧同样保持不变，恢复后继续自动 3×。时钟跳转计数为 1，对应实际向后跳转；正常播放的 934 对同条滚动位置均连续变化，没有回退或超大步进。
- 后一段连续 DXGI 区间约 49.58 秒、159.97 次 Present/s，提交间隔 P95 6.427 ms；命中穿透通过，无图形错误。

以上是本机 4K 覆盖层的短时验证；背景视频为 25 fps 网格，不代表 4K 正片解码负载或完整全屏输入矩阵。暂停稳定性按采样到的固定时间和位置验证，尚未测量按键到冻结的完整端到端延迟。

## 模拟设备丢失恢复

运行 --smoke --portable --simulate-device-loss --seconds 40，在中途注入与 DXGI_ERROR_DEVICE_REMOVED 相同 HRESULT 的应用内异常，进入实际资源释放、延时、创建和呈现路径；不重置系统显卡。

artifacts/alpha3-recovery-continuous 记录 3,769 帧，重建前 663 帧、重建后 3,106 帧；重建次数 1，图形错误为空，恢复后继续当前预览时间，时钟重建计数 0。相邻正常帧无回退、超大步进或同条滚动停顿，穿透检查通过。

此检查验证应用恢复路径，不代替真实驱动重置、显卡切换、显示设备拔插或系统休眠。

## 帧率上限

60 FPS 档：artifacts/alpha3-cap60-visible 记录 1,235 帧，连续有效区间约 20.96 秒、58.79 次 Present/s，提交间隔 P95 17.558 ms，图形错误、回退和移动停顿均为 0，命中穿透通过。

120 FPS 档：artifacts/alpha3-cap120-confirmed 记录 6,070 帧，连续有效区间约 51.91 秒、116.87 次 Present/s，提交间隔 P95 9.067 ms，图形错误、回退和移动停顿均为 0，命中穿透通过。

上限是提交节奏，实际呈现受 DWM 和显示器影响；不同物理刷新率下的 5 分钟验收仍待完成。
