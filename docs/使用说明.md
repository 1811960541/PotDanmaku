# PotDanmaku 使用指南

PotDanmaku 是 PotPlayer 的本地弹幕工具。PotPlayer 负责播放视频和对白字幕，PotDanmaku 负责在透明覆盖层绘制弹幕。

## 安装与启动

从 [GitHub Releases](https://github.com/1811960541/PotDanmaku/releases) 下载 Windows x64 便携 ZIP，完整解压到可写目录，运行 `PotDanmaku.App.exe`。便携包包含 .NET 运行环境；PotPlayer 需要另行安装。

默认只允许同一配置目录运行一个工具实例，再次启动会打开已有设置窗口。关闭主窗口退出程序；“收起到托盘”可保留后台同步。

## 加载与切集

在 PotPlayer 打开本地视频后，工具默认自动连接唯一的播放器；存在多个播放器时，手动选择要连接的窗口。点击停止会暂停自动连接，之后点击“连接并播放弹幕”继续使用。

识别到视频路径后，按以下顺序查找弹幕：

1. 该视频保存的、仍然存在的弹幕关联。
2. 视频同目录、相同主文件名的 `.xml`。
3. 同目录、相同主文件名的 `.json`。
4. 同目录、相同主文件名的 `.ass`。

例如 `第01集.mkv` 对应 `第01集.xml`。文件名需要准确匹配，不模糊猜测集数。也可以选择或拖入不同名称、不同目录的弹幕，成功导入后会记住当前视频的关联。先导入再连接播放器时，会将这份弹幕关联到识别到的视频。

播放器打开其他视频或进入下一集时，会清除旧弹幕并重新匹配。没有匹配文件时保持连接并提示手动选择。网络来源或无法取得本地路径的播放器版本仍可手动导入，但不能按本地视频路径保存关联。

每次只维护一个弹幕会话，不能同时为多个视频显示各自的弹幕。连接另一个播放器会停止原会话。

## 显示与时间调整

默认使用顶部 25% 的显示区域、小字号和 18 秒横穿时长。行数按字号、描边和可用空间计算；过密或过长的弹幕可能被跳过，界面提供统计。

“横穿时长”按视频时间计算，18 秒在 3 倍速播放时约为 6 秒实际时间。需要更慢的移动速度时增加该值。倍速通常保持“自动读取（含 3×）”；只有播放器未返回有效倍速时才使用手动降级，并保持与播放器设置一致。

“弹幕延后”以秒为单位，正数延后、负数提前。暂停时调整偏移也会立即生效。手动导入新文件时偏移重置为零，随后调整会按当前本地视频保存；重新打开该视频会恢复。

可调整字号、密度、透明度、描边、颜色、固定弹幕时长和最多行数。“跟随显示器”及 60/120 FPS 选项控制提交频率，实际显示节奏仍取决于显示器和系统合成。

覆盖区域根据播放器客户区、四边距和视频宽高比估算。如果弹幕覆盖播放列表、控制栏或黑边，展开“覆盖区域校准”调整边距；边距单位是播放器客户区的百分比。

“显示弹幕”只开关显示，不停止时间同步；重新开启会显示当前应出现的内容。“独立预览”不依赖播放器，没有导入文件时使用内置示例。

## 暂停与后台观看

普通暂停会冻结当前弹幕位置，恢复后继续移动。由于播放器进度接口存在缓存，暂停后的首个缓存周期内，第一次小幅向前跳转可能被误认为最终暂停位置补报而忽略；再次调整、稍后调整、向后或大幅跳转仍生效。

切到其他软件后，只要视频仍可见，弹幕会继续显示。其他窗口遮住视频时，也会遮住相应弹幕；播放器最小化、隐藏或被系统遮蔽时，覆盖层隐藏。需要让视频一直位于其他软件之上时，可使用 PotPlayer 的置顶功能。

## 文件格式

### XML

支持常见 B 站 XML：

```xml
<i><d p="1.25,1,25,16777215,0,0,0,0">示例弹幕</d></i>
```

类型 1/2/3 为滚动、4 为底部固定、5 为顶部固定、6 为反向，特殊类型跳过并报告。

### JSON

使用明确的 `potdanmaku/v1` schema，时间单位为整数毫秒：

```json
{
  "schema": "potdanmaku/v1",
  "timeUnit": "ms",
  "comments": [
    { "time": 1250, "text": "示例弹幕", "mode": "scroll", "color": "#5EEAD4", "opacity": 0.9 }
  ]
}
```

每条必须有 `time`、`text`；可选 `id`、`mode`（`scroll`、`reverse`、`top`、`bottom`）、`color`、`opacity` 和 `fontSize`。未知 schema 拒绝导入，未知 mode 单条跳过。其他导出器的 JSON 需要先转换到该格式。

### ASS

读取 Events 的时间、正文、样式主颜色与透明度，支持水平 `move`、固定 `pos` 和基础初始颜色/透明度覆盖，再按工具设置重新排布。原坐标、字体、原结束时间和复杂动画不会原样复现。XML/JSON/ASS 原始字号作为元数据保留，显示统一使用界面字号。

普通对白默认排除；勾选“也导入无定位的普通字幕”可以包含。导入后可使用“ASS 按样式筛选…”选择样式；显式选中的样式会包含其中的普通对白，混合文件应注意区分对白和弹幕样式。

卡拉 OK、绘图、旋转、变换、分段覆盖、非水平运动和复杂 Effect 等事件会跳过并报告。`Timer` 非 100 时提示，当前仍按 Events 时间导入，不自动缩放。请保留 PotPlayer 的对白字幕，关闭同一份弹幕 ASS 的播放器渲染，避免重复。

### 编码与导入报告

默认严格读取 UTF-8，支持 UTF-8/UTF-16 BOM。旧编码文件可选择 GB18030 后重新导入。单条坏记录或不支持的特性会显示在导入报告中；原始文件始终只读。

文件上限为 100 MB、50 万条记录，正文上限为 500 个 Unicode 字符。导入和排布可取消。手动导入失败时保留上一份有效文档；切集找不到文件或导入失败时不继续显示上一集弹幕。

## 设置保存与升级

便携版默认将数据放在程序旁的 `data`；不可写时提示并回退到 `%LOCALAPPDATA%\PotDanmaku`。源码普通模式也使用后者，可通过 `--portable` 或程序旁的 `portable.flag` 启用便携模式。

- `settings.json`：全局显示设置。
- `video-associations.json`：按视频完整路径保存的弹幕关联、偏移、显示设置、编码和 ASS 筛选选项。
- `logs`：滚动状态日志。
- `diagnostics`：手动导出的诊断。

不同目录的同名视频各自保存设置；移动或重命名视频后视为新视频。配置使用原子保存并保留备份。

升级时先退出旧版，完整解压新包，再将旧版 `data` 复制到新目录；不要只替换一个 EXE。程序不会移动视频或弹幕文件。

## 排查问题

看不到弹幕时，先确认选择了正确的播放器、导入报告存在成功记录、“显示弹幕”已开启且当前视频时间对应弹幕内容。复杂皮肤可手动调整覆盖区域。

“诊断与统计”可导出同步和绘图信息，也可手动重建绘制层。诊断不保存弹幕正文，但可能包含文件名、播放器标题和路径；分享前请移除个人信息。

问题反馈入口：[GitHub Issues](https://github.com/1811960541/PotDanmaku/issues)。请提供工具、Windows 和 PotPlayer 版本、弹幕格式及可复现步骤。
