# 文件导入与轨道验证

日期：2026-10-04。版本：0.1.0-alpha.1。M1–M3 主要功能已实现，M4/M5 完整验收尚未完成。

后续发现：本轮“高提交帧率”不能证明实际移动连续。alpha.1 的播放器时钟存在延迟采样锚点错误，会周期性超前并回拉；已经在 alpha.2 修复，详见 [平滑移动修复](平滑移动修复.md)。本记录的暂停与导入结果保留，但不能把本轮播放计数解释为通过了平滑观看验收。

## 实现

- Core 增加统一弹幕、排布设置、不可变时间表、二分活跃查询；seek 直接读取对应时刻的集合。
- Formats 增加 B 站 XML、明确毫秒单位的 JSON v1、ASS 重排子集、严格解码、资源上限、取消与报告。
- 使用 DirectWrite 实测字宽、字高；比较共同存活区间内的相对位置端点，防止更长、更快的后续弹幕追尾；滚动、反向和固定弹幕共享占用检查。
- GPU 线程绘制全部活跃弹幕，文字布局缓存上限 2,048，按最近使用顺序淘汰；每帧不再扫描完整源文件。
- 界面增加文件选择/拖入、导入报告、编码与普通 ASS 选项、区域/字号/时长/透明度/密度/行数/描边/颜色、时间偏移、持久配置。
- 修复错误文件导致的未捕获 InvalidDataException；失败保留已有弹幕。视频刚打开时若宽高查询返回 0，每秒重试到获得有效比例。

预览出现一次较长间隔，不能宣称密集输入全程没有卡顿；其 DXGI 有效段也只覆盖约 12 秒。播放器测试的有效段更长，仍不是物理逐帧测量，也不是 4K 全屏、全部倍速或长时验收。没有确认实际 D3D11 设备选中哪张 GPU，不能归属某显卡的成绩。

## 界面与失败路径

通过界面调节字号，关闭并重启后恢复了修改值，再使用预设恢复 16 / 18 秒 / 顶部 25%。修复深色界面下 Expander 标题不可读的问题，整数设置改成整档调节，边距保留小数调节。

无 schema 的 JSON 通过导入失败路径正常返回退出码 1，保留上一份弹幕，没有弹出未处理异常。证据：`artifacts/invalid-import/`。错误配置版本与结构错误会回退默认配置并提示。
