# 后台可见播放器的弹幕叠加修复

日期：2026-10-04。版本：0.1.0-alpha.4。环境：本机 Windows 11 x64。

后续反馈：用户已确认“没有问题了”，并要求打包独立版本。独立便携包冻结 alpha.4 的程序二进制，默认便携配置并附运行环境；这次日常确认不等于尚未执行的完整兼容矩阵已经通过。

## 问题与修改

旧版本要求目标播放器必须是前台窗口；点击浏览器、编辑器、工具设置或其他区域后，即使视频仍可见，也会隐藏弹幕，不适合边看边做事。

alpha.4 取消前台限制。播放器可见、未最小化、未被 DWM 遮蔽，且有有效播放采样和布局时，继续显示弹幕；失焦不重设时钟。独立预览使用相同窗口规则。显示开关、停止播放、读取失效和设备恢复仍保留原有隐藏条件。

同时移除覆盖层的无条件全局置顶。每次定位读取播放器的窗口层级和置顶属性，只调整覆盖层，将它插入目标窗口正上方。上层窗口可以遮住视频及对应弹幕，不修改播放器或工作窗口的层级，不抢焦点，不建立跨进程窗口所有者关系。播放器自行置顶时，覆盖层跟随该属性；取消置顶时，覆盖层也降回普通窗口层级。

命中检查改为验证覆盖层不接收鼠标：视频被其他软件盖住时，应由上层软件正常接收输入。诊断增加 window-samples.json，记录可见性、目标是否前台、最小化、DWM 遮蔽、置顶属性、覆盖层相对位置及定位前后焦点是否变化，不记录其他软件标题或正文。

- 上述真实播放器记录包含实际 1×/3×切换和跳转，不能按纯连续 3× 基准解释通用分析脚本中的回退、跳转和暂停计数。本次只据此判断失焦可见性和窗口协调；之前的稳态 3× 结果仍见 3倍速与M4验证.md。
- artifacts/alpha4-window-lifecycle：普通、非置顶的独立预览约 65 秒，全程目标不在前台。515 条窗口记录中的前 3 条处于初始化排布阶段，后 512 条全部保持覆盖层可见；可见时目标与覆盖层都为非置顶，相对层级错误 0，定位期间前台窗口变化 0，无图形错误，命中穿透通过。

## 多视频支持边界

当前能识别多个 PotPlayer 实例并选择其中一个连接；主程序只维护一份文件、一个采样任务、一个媒体时钟和一个覆盖层。连接另一个目标会先停止旧会话，因此尚不支持同时给多个视频分别显示弹幕。多视频独立会话已列入后续开发计划，本次没有把单目标后台显示当作多视频功能。

实现依据：[Microsoft GetWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindow)、[SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)、[DWM 窗口属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)。
