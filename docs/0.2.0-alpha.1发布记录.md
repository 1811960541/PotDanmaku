# 0.2.0-alpha.1 发布记录

日期：2026-11-12。Windows x64 自包含便携试用版。

本次按用户要求完成此前暂缓的打包，包含同名弹幕自动加载、播放列表切集、按视频保存弹幕关联/偏移/显示设置，以及暂停闪动、回退和恢复后的误判跳转修复。原有 3×、图标、托盘和后台叠加功能保留。

## 产物与使用

- `releases/PotDanmaku-0.2.0-alpha.1-portable-win-x64/`：可直接运行的独立目录。
- 同名 `.zip`：分发用压缩包，完整解压后运行 `PotDanmaku.App.exe`。
- 同名 `.zip.sha256`：整个 ZIP 的 SHA-256。
- 同名 `.verification.json`：最终压缩包、文件清单、格式导入和包内 CLR 验证报告。
- 同名 `.session-verification.json`：实际发布程序集的关联/切集及真实暂停恢复报告。
- 同名 `.icon-verification.json` 与 `.smoke-verification.json`：图标及解压后程序启动/预览检查结果。

包自带 .NET 10.0.12 的 Windows x64 运行环境，不需要 SDK 或项目源码；仍需另行安装 PotPlayer 和支持 D3D11 的显卡驱动。旧 alpha.6 发布目录与 ZIP 保留。

升级时先退出旧程序，解压新包，再复制旧目录的 `data` 文件夹以保留配置；不要只替换 EXE。新包不带开发机的个人配置、视频、完整弹幕、日志或测试产物。程序运行后创建的 `data` 不属于冻结发布文件。

## 复跑

```powershell
.\tools\verify-portable.ps1 -ZipPath releases/PotDanmaku-0.2.0-alpha.1-portable-win-x64.zip -ReportPath artifacts/alpha020-portable-verification.json
dotnet publish tests/PotDanmaku.SessionTests -c Release -r win-x64 --self-contained true -o artifacts/PotDanmaku.SessionTests-win-x64
.\tools\verify-release-session.ps1 -PackageDirectory releases/PotDanmaku-0.2.0-alpha.1-portable-win-x64 -ReportPath artifacts/alpha020-session-verification.json -RealPlayerExecutable 'C:/Path/To/PotPlayerMini64.exe'
```

不传 `-RealPlayerExecutable` 时仅执行关联与切集会话检查。检查复制发布文件到独立临时目录，不向冻结的发布目录写入测试驱动或用户数据。

## 剩余验收与限制

本机项目外自包含运行验证不等于无预装 .NET 的干净 Windows 验收。日常正片观看、完整倍速切换/全屏输入、多屏 DPI、真实休眠/设备变化、两小时稳定性及本版托盘菜单人工复验仍按开发计划保留。

仍一次只维护一个播放器弹幕会话；自动匹配要求可识别的本地视频路径；JSON 仍要求既定 schema。暂停后首个缓存周期内立即小幅前跳，可能被当作最终暂停位置补报而忽略，规则见 [暂停衔接修复](暂停衔接修复.md)。自动关联和迁移规则见 [自动加载与视频设置记忆](自动加载与视频设置记忆.md)。
