# M0 实施与验证记录

日期：2026-10-04。状态：**原型实现和首轮验证完成，M0 的完整验收仍有待测项**。

## 实施结果

- 建立 .NET 10 solution、核心库、WPF 控制面板和 xUnit 测试项目。
- 使用真正的 Win32 HWND 承载 DirectComposition，不使用 WPF 的逐帧绘制。
- GPU 管线为 D3D11 → DXGI 组合交换链 → D2D/DirectWrite → DirectComposition。
- 覆盖窗口使用分层、透明、非激活工具窗口样式；绘制资源只在专用线程创建、使用、销毁。
- 50 ms 周期在后台查询 PotPlayer，单个通信调用设置 20 ms 超时；不写播放器设置。
- 实现单调时钟外推、小误差调整、暂停/恢复、跳转、采样过期冻结、停滞检测与小幅暂停跳转处理。
- 提供单行循环测试、独立预览、字号/时长设置、区域边距校准、CSV/JSON 诊断和只读探针。
- 发布自包含包：`artifacts/PotDanmaku-M0-win-x64`。

图形原型使用系统默认硬件适配器；本轮未单独确认 D3D11 设备实际选中了哪张显卡。因此不能把测量结果归属为 RTX 5080 单卡成绩。

## 自动测试

`dotnet test PotDanmaku.sln -c Release`：11/11 通过。

覆盖：25 fps 时间量化下的时钟单调性、暂停/恢复、前后跳转、暂停时 40 ms 小跳转、倍速变化、断连外推上限、停滞、过期样本、非法数据和帧时间长尾统计。

最初的暂停恢复测试发现：恢复时把暂停累计时长误判为停滞。已在播放状态转换时重置进度变化计时器，回归通过。

编译与发布：0 warning、0 error。自包含包可以运行只读探针；尚未在完全没有 .NET 的干净虚拟机验收。

## 工程决策与待办
